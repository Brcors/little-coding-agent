# v0.2 本地工作台交付记录

日期：2026-11-01。

本记录保留 v0.2 工作台交付范围。后续版本增加了需求解析、工具层和语义执行；最新 v0.5 状态见 [语义与工具调用实现](semantic-function-calling.md)。

## 实现

React + TypeScript + Vite 前端；Lucide 图标和响应式 CSS；Node.js 原生 HTTP 后端；SSE 推送任务快照。直接调用现有 Agent 核心、工具、执行器和工作区逻辑。

界面支持新建演示 / 真实任务、浏览本机文件夹、查看任务历史、停止当前任务、审阅差异、接受与丢弃、查看每次检查日志、下载报告和查看模型配置说明。

服务只监听 loopback；API 使用同源会话、CSRF、Origin / Host 校验；网页不能请求任意宿主检查，真实任务只提供 Docker 或 disabled。API Key 仍从后端 .env 读取。
